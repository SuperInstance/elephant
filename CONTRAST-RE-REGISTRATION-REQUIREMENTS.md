# Contrast Head — Re-Registration Requirements (thesis author's steer, 2026-08-19)

Applies to the contrast head's dated re-registration event (Phase 0.5, MUST precede any clean training).

1. The re-registration event MUST name its PRIMARY coarse definition explicitly: either
   (a) REGISTER AXIS — flat-music-vs-speech (the corpus as it structurally exists), or
   (b) ROOM AXIS — cross-room contrast from data/nights/ (room-to-room displacement).
2. The alternative definition is REPORTED AS A SECONDARY measurement — a reported number, NOT a
   fallback if the primary disappoints. Picking the primary after seeing results = soft narration.
3. The event records the date, the definition chosen, and the rationale — before training begins.
4. Fine leg (0.0146 → ≥0.10 deadman) is re-affirmed unchanged; only the coarse leg is re-registered.

If this file is present, treat it as binding on the re-registration event's content.
